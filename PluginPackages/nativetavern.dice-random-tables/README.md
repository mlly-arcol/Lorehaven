# 掷骰与随机表

在 Lorehaven 中安装并启用后，可在聊天中手动输入 `d20`、`2d6+1` 等表达式掷骰，或从插件提供的加权随机表中抽取结果。掷骰与抽取均在本机完成，不调用 AI。

随机结果可保存在当前对话中。默认情况下，它不会进入模型上下文；只有用户明确选择加入时，模型才会看到该结果。停用插件后，随机表不再可选，已经保存的历史结果仍保留。

## 自定义随机表

插件根目录中的 `random-tables.json` 使用 `formatVersion: 1`，包含 1–20 张表。每张表包含唯一的小写 `id`、`name`、可选 `description` 和 1–100 个 `entries`。每个结果包含不超过 500 字的 `text` 和 1–10000 的整数 `weight`。权重越高，被抽中的概率越大。

该插件使用受控的 `dice-random-tables-v1` 声明式能力，不包含或执行第三方代码。
